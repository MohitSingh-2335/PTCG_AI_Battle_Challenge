# PTCG AI Battle Challenge Research Bundle

This folder is a curated reference set built from public competition pages, simulator documentation, and the key official discussion thread about simulator differences.

It is intentionally a summary bundle, not a raw mirror of the webpages. The goal is to keep the important constraints, submission rules, and simulator behavior in one local place for agent development.

Contents:
- `sources.md` - URLs and what each source covers
- `simulation_competition.md` - simulation track summary
- `strategy_competition.md` - strategy/writeup track summary
- `cabt_engine.md` - simulator API and observation/action model
- `data_and_replay_notes.md` - dataset, replay, and submission packaging notes
- `simulator_differences.md` - known simulator vs official rule differences and edge cases
